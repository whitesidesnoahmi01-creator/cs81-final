# Job Application Tracker

## Project Summary

This project is a React application that helps users manage their job applications. Users can enter information about their job application, view saved applications, update existing entries, and delete applications.

## Key Features and Functionality

- Add a new job application
- View all saved job applications in a table
- Edit an existing application
- Delete an application
- Track the company name, position, date applied, and application status
- Choose between Applied, Interviewing, Offer, and Rejected statuses
- Prevent form submission when required fields are empty
- Save application data with localStorage
- Display visual feedback when an application is added or updated
- Change the form appearance while editing an application
- Responsive form layout for smaller screens

## Technologies Used

- React
- JavaScript
- JSX
- HTML
- CSS
- localStorage
- Vite

## Instructions for Use

1. Enter the company name
2. Enter the position title
3. Select the date when the application was submitted
4. Choose the current application status
5. Click **Add Application** to add the application to the table
6. Click **Edit** to load an existing application into the form
7. Change the information and click **Save Changes** to update it
8. Click **Delete** to remove an application.
9. Refresh the page to confirm that the application data remains saved
